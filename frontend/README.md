# Koru

Koru is a modern full-stack web application built using React, TypeScript, Vite, Tailwind CSS, and shadcn/ui.

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone <YOUR_GITHUB_REPO_URL>
```

### 2. Navigate to the Project Folder

```bash
cd <PROJECT_NAME>
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The application will start on:

```bash
http://localhost:5173
```
